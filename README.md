# Library Management System

## Project Description
A web-based Library Management System developed as part of the CSE2552 – Software Configuration Management practical sessions at the University of Sri Jayewardenepura.

## Project Objectives
To develop a simple application for managing library books and lending activities while practising Software Configuration Management concepts.

## Features
- Add books
- View books
- Borrow books
- Return books
- Remove books
- Update book details

## Technologies Used
- HTML
- CSS
- JavaScript
- Git
- GitHub

## Project Structure
- `docs/` – Project documentation
- `src/` – Application source code
- `tests/` – Testing files
